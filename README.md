# ademdeniz.github.io

Portfolio of **Adem Garic**, QA Engineer (AI), SDET, and QA Analyst.

**Live:** https://ademdeniz.github.io

- **AI Quality:** LLM-as-a-judge evals, hallucination and guardrail testing, MCP tooling
- **SDET:** Appium 2, Selenium, Playwright, RestAssured, Jenkins, BrowserStack
- **Manual QA:** risk-based test plans, exploratory testing, bug reports that can be reproduced

The site is a single static `index.html` with no build step and no frameworks. It includes an interactive faithfulness "Eval Lab", a role-lens skills explorer, sample QA artifacts, and filterable projects.
